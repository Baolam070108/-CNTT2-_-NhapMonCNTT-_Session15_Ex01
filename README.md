# 1. Vấn đề là gì?

Bạn A chỉ lưu file thiết kế 3D trên ổ cứng máy tính và gửi qua Zalo. Khi ổ cứng bị lỗi, file bị hỏng và bản gửi qua Zalo hết hạn tải xuống, dẫn đến nguy cơ mất dữ liệu quan trọng.

**Nguyên nhân:** Không có bản sao lưu trên Cloud, không đồng bộ tự động và không có phương án khôi phục phiên bản cũ.

# 2. Yêu cầu là gì?
- Phân tích cách dữ liệu được chuyển từ ổ SSD lên Cloud.
- Nêu 3 bước thiết lập phần mềm đồng bộ dữ liệu lên Cloud.
# 3. Cách làm ra sao?
a. Luồng dữ liệu từ SSD lên Cloud:

Designer chỉnh sửa file → Nhấn Ctrl + S để lưu vào SSD → Phần mềm tự động đồng bộ file lên Cloud → Có thể khôi phục file cũ bằng Version History.

b. Ba bước thiết lập đồng bộ dữ liệu lên Cloud:
- Bước 1: Cài đặt Google Drive hoặc OneDrive và đăng nhập tài khoản.
- Bước 2: Chọn thư mục chứa file thiết kế và bật đồng bộ tự động (Auto Sync).
- Bước 3: Lưu file, kiểm tra file đã lên Cloud chưa và thử khôi phục bằng Version History khi cần.
