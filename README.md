# 1. Vấn đề là gì?

Bạn A chỉ lưu file thiết kế 3D trên ổ cứng máy tính và gửi qua Zalo. Khi ổ cứng bị lỗi, file bị hỏng và bản gửi qua Zalo hết hạn tải xuống, dẫn đến nguy cơ mất dữ liệu quan trọng.

**Nguyên nhân:** Không có bản sao lưu trên Cloud, không đồng bộ tự động và không có phương án khôi phục phiên bản cũ.

# 2. Yêu cầu là gì?

- **Tự động đồng bộ:** Khi nhấn `Ctrl + S`, file được lưu trên máy tính và tự động đồng bộ lên Cloud.
- **Khôi phục dữ liệu:** Sử dụng Version History để lấy lại phiên bản ổn định khi file bị lỗi.
- **Xử lý mất kết nối:** Khi mất Internet, file vẫn được lưu trên máy tính và tiếp tục đồng bộ khi có mạng trở lại.
- **Xử lý xung đột:** Khi có nhiều phiên bản khác nhau, giữ lại các thay đổi và chọn phiên bản phù hợp.
- **Bảo vệ dữ liệu:** Có thêm bản sao lưu cho các file quan trọng.

# 3. Cách làm ra sao?

**Bước 1: Cài đặt phần mềm**

Cài Google Drive hoặc OneDrive, đăng nhập tài khoản và tạo thư mục dự án Số hóa Bảo tàng PTIT để lưu file thiết kế.

**Bước 2: Bật đồng bộ tự động**

Thiết lập phần mềm tự động đồng bộ file lên Cloud sau khi nhấn `Ctrl + S`. Bật Version History để lưu lịch sử chỉnh sửa và khôi phục file khi cần.

**Bước 3: Kiểm tra hoạt động**

Thử lưu file khi mất Internet, sau đó kết nối lại để kiểm tra việc đồng bộ. Nếu file bị lỗi, sử dụng Version History để khôi phục phiên bản cũ. Kiểm tra trạng thái đồng bộ trước khi tắt máy.

**Cách hoạt động dễ hiểu:**

Bạn A sửa file trên máy tính → Nhấn `Ctrl + S` để lưu → Phần mềm tự động sao chép file lên Cloud → Nếu file bị lỗi, mở Version History để lấy lại bản cũ.

**Kết luận:** Cách làm này giúp nhóm hạn chế mất dữ liệu và khôi phục file khi xảy ra sự cố.
